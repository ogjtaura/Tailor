# Prompt and Agent Research

## Objective

Create model-specific, versioned role prompts and evaluate them empirically.

## Roles

- Sonnet planner
- Sonnet implementer
- Sonnet repairer
- Luna routine reviewer
- Terra adjudicator
- optional Sol/Opus meta-auditor

## Research themes

- direct task framing
- structured context
- stable prompt prefixes
- just-in-time repository retrieval
- minimal sufficient context
- structured repair feedback
- reasoning-effort selection
- tool/interface quality
- agentless/direct execution for small tasks
- prompt caching where applicable

## Required outcome

Prompts should be versioned and benchmarked.

Do not accept prompt changes because they merely sound better.
